# ЕЦС · TSX-компоненты из Figma

Раздел **Из макета** содержит все **93 исходные группы / 8 287 вариантов** в отдельных `.tsx` и `.module.css`. Повторные библиотечные версии сохранены с ID.

```tsx
import { ButtonDesign } from '@ecs/design-system/figma/ButtonDesign';
import '@ecs/design-system/figma/styles.css';

<ButtonDesign variant="227:719" text={{ Button: 'Открыть' }} onClick={openOffice} />
```

Это обычная React-разметка: DOM-текст, контейнеры и SVG отдельных векторных слоёв. Компоненты находятся в `src/figma/`, для каждого есть список `variants`, типизированные `variantProps`, текстовые слоты и CSS Modules.

- **Из макета** — прямое извлечение визуальных компонентов; Controls выбирают любой исходный вариант и меняют текст.
- **Компоненты / ЕЦС / Основы** — удобные API и готовое поведение форм, таблиц, карточек и чата.
- **Архив** — прежний справочник геометрии для аудита.

`interactive` включает hover/click-переходы, заданные в прототипе Figma. Для фиксированной сверки отключите его. Матрица States показывает исходные состояния рядом.

## Запуск и проверка

```sh
npm run storybook
npm test
npm run build
npm run build:storybook
npm run extract:tsx -- ../ецс.fig
```

Геометрия перенесена с фиксированными размерами из Figma. Поисковая логика select, редактирование текста, загрузка файлов на сервер и другие бизнес-процессы задаются приложением. Все исходные визуальные состояния доступны в TSX.

Основной шрифт — **SB Sans Text**, его файл в `.fig` не вложен. До подключения шрифта используется Arial; метрики текста могут отличаться. Сложное сглаживание и градиенты требуют визуальной сверки.

Полное руководство: `docs/extracted-tsx.md`. Карта семейств: `src/figma/catalog.json`.
