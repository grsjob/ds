# TSX-компоненты из исходного макета

`src/figma/` содержит прямое извлечение всех 8 287 SYMBOL-вариантов в 93 самостоятельных TSX-семейства и CSS Modules. Повторные версии библиотек сохранены отдельно с ID в имени, чтобы не потерять различия.

Каждое семейство имеет структуру:

```text
src/figma/ButtonDesign/
  ButtonDesign.tsx
  ButtonDesign.module.css
  index.ts
  layers.json
```

В TSX записана обычная разметка React: span/button, текстовые узлы и inline SVG отдельных векторных слоёв. Нет fetch дерева Figma, JSON-рендерера, canvas или картинки целого компонента. `runtime.ts` содержит только выбор варианта, подстановку текстовых слотов и обработку переходов прототипа.

## Использование исходников

```tsx
import { ButtonDesign } from './src/figma/ButtonDesign';

<ButtonDesign
  variantProps={{
    state: 'primary',
    size: 'M',
    'Icon left': 'off',
    'icon right': 'off',
    text: 'on',
    action: 'default',
  }}
  text={{ Button: 'Сохранить офис' }}
  onClick={saveOffice}
/>
```

Названия и допустимые значения `variantProps` сохранены из Figma и перечислены в интерфейсе `ButtonDesignDimensions`. Можно задавать неполный набор свойств: будет выбран первый соответствующий вариант. Несуществующая комбинация вызывает явную ошибку. Для однозначного выбора используйте `variant` с ID исходного SYMBOL:

```tsx
import { ObjectCardDesign } from './src/figma/ObjectCardDesign';

<ObjectCardDesign
  variant="227:70776"
  interactive={false}
  text={{ 'Text text text text': 'Параметры офиса' }}
/>
```

Для замены отдельного вхождения используйте полный ключ из `layers.json`. Подстановка по имени заменяет все текстовые слои с таким именем; подстановка по ключу имеет приоритет. Значение — ReactNode, null скрывает текст, исходная компоновка сохраняется.

```tsx
<ButtonDesign
  variant="227:719"
  text={{ '227:719/227:721': 'Открыть' }}
/>
```

`as="span" | "button" | "div"` меняет корневой HTML-элемент. Для семейств кнопок по умолчанию используется нативный button с type=button. Для остальных — span; передавайте необходимые role/aria-* и обработчики, если используете их как интерактивные контролы.

## Использование собранного пакета

```tsx
import { ButtonDesign } from '@ecs/design-system/figma/ButtonDesign';
import '@ecs/design-system/figma/styles.css';
```

Есть общий экспорт `@ecs/design-system/figma`, но импорт отдельного семейства удобнее для сборщика. Команда `npm run build` собирает основную библиотеку, извлечённые компоненты и декларации типов. Только извлечённую часть собирает `npm run build:figma`.

## Storybook

Раздел **Из макета** содержит отдельную страницу каждого семейства, полный список вариантов в Controls и матрицу состояний, если в семье есть ось состояния. `variant` выбирает точный исходный вариант, `variantProps` — сочетание измерений, `text` меняет содержимое, `interactive=false` фиксирует выбранное состояние.

`interactive=true` воспроизводит заданные в Figma переходы SWAP_STATE для hover и click. Уход курсора возвращает исходное состояние, выбранное кликом состояние сохраняется. Действия приложения, внешняя навигация и обращения к сервисам автоматически не запускаются. Обработчик приложения onClick вызывается отдельно и может отменить переход через preventDefault().

## Что сохранено

- Все SYMBOL-варианты, включая неиспользуемые и библиотечные копии.
- Размеры, расположение, поворот, видимость, opacity, отдельные радиусы, заливки, обводки и тени.
- Instance overrides: текст, стили, вложенная замена символа и сохранённая Figma геометрия.
- Векторные сети, кривые Безье, области, заливки, обводки и boolean-группы union/subtract.
- Вложенные изображения, необходимые семействам, в `src/figma/assets/`.
- Типографические параметры и текст как редактируемый DOM, а не контуры букв.

## Практические границы

Это прямой перенос визуальных компонентов из Figma с фиксированной геометрией. Он не превращает нарисованное поле в полноценный редактор или поисковый select. Прикладное поведение, адаптивные правила, клавиатурные сценарии сложных контролов и данные должны задаваться отдельно. Для готового поведения уже есть компоненты в `src/components/`; их покрытие описано в `coverage.md`.

Файл шрифта SB Sans Text не вложен в .fig; до его подключения метрики текста отличаются. Векторная геометрия декодирована, но сложное сглаживание, vertex corner smoothing, ромбические градиенты и все детали рендеринга Figma не гарантируют пиксельное совпадение в браузере. Автоматические проверки всех вариантов проверяют успешный рендер, а не визуальное равенство всех 8 287 изображений.

## Повторная генерация

```sh
npm run extract:tsx -- ../ецс.fig
```

Нужны Node.js и Python 3. Исходный файл читается без изменений. Генерация перезаписывает `src/figma/` и `stories/extracted/`: ручные изменения этих файлов сначала сохраните отдельно. Прикладные компоненты в `src/components/` генератор не меняет.
