# Проверка

Проверено 15 октября 2026 года.

## Прямое извлечение

- 93 отдельных TSX-семейства и 93 CSS Modules в `src/figma/`.
- Все 8 287 SYMBOL-варианта представлены в TSX.
- 69 815 узлов React-разметки с учётом раскрытых экземпляров и их переопределений.
- 4 исходных встроенных изображения, необходимые этим семействам.
- Генератор не сообщает о потерянных векторных путях; дуги, векторные сети, union/subtract и текстовые style ranges обработаны.

## Автоматические проверки

- `npm test`: 15/15 тестов проходят, включая последовательный рендер всех 8 287 вариантов через React DOM Server.
- Проверены text slots и сохранение onClick, disabled-вариант исходной кнопки, реальные hover/click-переходы Chip.
- Регрессионная проверка карточки подтверждает исходные вложенные подписи УТНФ, ШВ2В и МВС вместо текста мастер-компонента Button.
- Сохраняются 10 проверок поведения основной библиотеки: формы, выбор, вкладки, чат, удаление Chip и Disclosure.
- `npm run build`: успешны TypeScript, обе ESM-библиотеки, CSS и декларации типов.
- `npm run build:storybook`: успешно; 263 истории и 125 страниц документации.

## Браузер

Использован уже запущенный пользователем Storybook на localhost:6006. Проверены загрузка нового раздела «Из макета», рендер TSX-кнопки с исходной иконкой и матрица состояний ObjectCardDesign. После визуальной проверки исправлены inline-baseline SVG и сопоставление guidPath для текстовых переопределений внутри вложенных фреймов.

Снимок: [storybook-tsx.png](storybook-tsx.png).

Эти проверки подтверждают успешный рендер и перечисленные сценарии. Они не являются пиксельным сравнением всех вариантов с Figma. Для точных текстовых метрик нужен файл SB Sans Text; сложное сглаживание и детали градиентов остаются предметом визуальной приёмки. Компоненты сохраняют фиксированную геометрию макета и не восстанавливают из рисунка бизнес-логику приложения.

Полное руководство: [extracted-tsx.md](extracted-tsx.md).
